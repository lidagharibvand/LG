# Changelog

## 1.0.0

First release, matching the first printing.

- One folder per chapter, `ch01_introduction` through
  `ch14_big_data`.
- The eleven named datasets of Appendix G, with the script that
  generates them.
- Chapter 13 code examples in R, SAS and SPSS, named
  `ex13_<language>_<nn>_<task>`, with the trial dataset they run
  against and its codebook.
