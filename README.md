# HALO: companion datasets and code

Companion repository for two books by **Lida Gharibvand, MS, PhD**:

- *Modern Biostatistics for the Health Sciences, Volume I: Health Research Methods and Study Design*
- *Biostatistics with R & AI, Volume II: An Interactive Guide to Data Analysis*

Both volumes run on the same simulated health system, so the data you download here
serve the whole series. Free to use for learning and teaching. Please see
**Terms of use** at the end of this page.

## What is HALO

HALO (Heart And Lipid Outcomes) is a **simulated** health system built for teaching.
At its centre is a randomized lipid-lowering trial of 2,000 participants, drawn from a
clinic panel of 6,000 patients, with a hospital encounter extract, a patient experience
survey, a ward log and five years of service-area vital statistics around it.

No participant, clinic, ward, physician or treatment in HALO exists. Nothing in it is
evidence about a real treatment, and no figure computed from it describes any real
population. It was designed and generated by the author and is not derived from any
real patient record, registry or trial.

Several files carry **documented planted errors**: an impossible body mass index, a
slipped decimal point, sentinel codes standing in for missing values, duplicated rows
and a department spelled two ways. They are there on purpose, so that data quality can
be taught by finding faults rather than by being warned about them.

## What is here

| Folder | What it holds |
|---|---|
| `datasets/` | The HALO data files. `halo.csv` is the main file used throughout both books. The others (long format, hand-work subset, clinic panel, hospital extract, survey, ward, vital statistics) are used in particular chapters. Each comes as `.csv`, `.xlsx`, `.sav` (SPSS) and `.xpt` (SAS transport), so you can open them in the software you already use. |
| `Volume-II/code/` | One script per part of Volume II, holding every listing in the order the book prints them, followed by the code panels of the exercises. The `figures_*.R` scripts draw the printed figures. |

## How to use it

1. Click the green **Code** button and choose **Download ZIP**, or download single files
   from the `datasets` folder. You do not need a GitHub account.
2. Put the `datasets` folder inside your RStudio project folder.
3. Every script reads the data the same way:

   ```r
   halo <- read.csv("datasets/halo.csv")
   names(halo) <- tolower(names(halo))   # the file spells the column BMI
   ```

   so run the scripts from the project folder, the one that holds `datasets`.
4. Open a script and run it line by line with Ctrl+Enter (Cmd+Return on a Mac), or all at
   once with Source. The listings of a chapter share one R session, so run them in order.

Packages: install one with `install.packages("dplyr")`. The figure scripts also use
`ggplot2`, `gridExtra` and `patchwork`. Some scripts write files into folders called
`output` and `figures` inside your project.
